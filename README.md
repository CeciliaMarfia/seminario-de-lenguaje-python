# Seminario de Lenguaje: Python

Actividades, entregas y trabajo integrador del Seminario de Lenguaje Python (Facultad de Informática, UNLP).

## Estructura

- `teoria/`: material de las clases 1 a 11.
- `practica1/`, `practica2/`: prácticas de la cursada.
- `act3porpythonplus/` a `act6porpythonplus/`: actividades de Python Plus en Jupyter Notebook.
- `entrega1/`, `entrega2/`: entregas individuales.
- `grupo22/`: trabajo integrador grupal: aplicación en Streamlit con análisis de datasets abiertos de Argentina.
- `informeFinal/`: informe final.

## Temas

- Tipos de datos, estructuras y funciones
- Manejo de archivos CSV y JSON
- Análisis de datos con pandas en Jupyter
- Aplicaciones web con Streamlit

---

Las resoluciones son propias y pueden tener errores. El material de cátedra (diapositivas, enunciados y parciales) pertenece a sus docentes y está incluido solo como referencia de estudio.
